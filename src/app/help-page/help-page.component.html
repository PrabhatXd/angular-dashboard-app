Help & Support

Get quick answers and guidance on how to use the application effectively.

How do I log in to the application?

Use your registered username and password. Authentication is handled securely using the Auth Service.

What information is shown on the dashboard?

The dashboard displays real-time metrics, charts, and summaries built using Angular Highcharts.

How does navigation work?

The side navigation bar allows you to move between Dashboard, Users, Products, Contact, and Help pages.

How can I contact support?

Visit the Contact page and submit your query. Our team will respond promptly.
